# Vendor Performance Analysis

## Overview

Vendor Performance Analysis is a data analytics project that evaluates vendor purchasing and sales performance using Python, SQL, SQLite, and Pandas. The project follows a complete data analytics workflow, including data ingestion, SQL-based analysis, exploratory data analysis (EDA), and business insight generation to support data-driven decision making.

For detailed methodology, analysis, and business recommendations, please refer to the project report.

---

## Objectives

- Analyze vendor purchasing and sales performance.
- Identify high-performing and low-performing vendors.
- Evaluate the impact of bulk purchasing on unit price.
- Perform exploratory data analysis (EDA) on inventory, purchase, and sales data.
- Generate actionable business insights using SQL and Python.
